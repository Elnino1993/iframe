Виджет FaveRadar (faveradar.xyz)
================================

Статичный блок без сборки и без своего сервера. Данные об анкетах он берёт с сервера FaveRadar
(адрес задан в config.js). Показывает только подписанные ссылки из админ-конструктора сайта.

Файлы
-----
  index.html    каркас страницы + CSP (какие адреса можно грузить)
  widget.js     вся логика: загрузка данных, 18+, виды карточек (cards / photos / list), скрытие полей
  widget.css    оформление: цвета, карточки, 2 колонки с горизонтальным фото, мобильная версия, SEO-страницы
  seo.js        окно 18+ и заглушки для битых фото на SEO-страницах (ответ 18+ общий с виджетом — ключ fr:age)
  config.js     адрес сервера данных: api: 'https://api.faveradar.com'
  vercel.json   настройки Vercel: iframe (frame-ancestors *) и no-cache для виджета, адреса SEO-страниц
                (/tops и /<адрес> → pages/…html), кэш 5 минут для страниц, sitemap и robots
  .vercelignore что не выкладывается на Vercel (README, dev/, seo/, package.json, *.cmd)
  package.json  только команда npm run dev (локальная разработка)
  dev/          локальный сервер, демо-данные, песочница и редактор SEO-страниц
  seo/          данные SEO-страниц (pages.json, creators.json) и сборщик build.mjs — на Vercel не выкладывается
  pages/        готовые SEO-страницы (создаются кнопкой «Собрать страницы», руками не править)
  img/c/        лёгкие копии фото анкет (AVIF/WebP 320 и 640 px), тоже создаются при сборке
  sitemap.xml, robots.txt   создаются той же сборкой
  start-dev.cmd, seo-editor.cmd   ярлыки: песочница виджета и редактор SEO-страниц

Как править локально (без сайта и сервера)
-------------------------------------------
Нужен только Node.js 18+. Зависимостей нет, npm install не нужен.

  1. Дважды щёлкните start-dev.cmd (Windows) — откроется браузер с песочницей.
     Или в терминале в этой папке: npm run dev
  2. Окно с сервером не закрывайте, пока работаете.
  3. Откройте http://localhost:5173/dev/ — это песочница: вид виджета (топ, подборка, хаб, карточка),
     рейтинг, страна/город, количество анкет, вид карточек (карточки / 2 в ряд с фото / список),
     галочки полей, тема, язык, цвет, картинки-заглушки, ширина превью (телефон/планшет/экран).
  4. Правьте widget.js / widget.css / index.html, сохраняйте и жмите «Обновить» в песочнице.

Как это устроено:
  dev/server.mjs     мини-сервер: отдаёт файлы виджета и демо-данные в том же формате, что настоящий сервер
  dev/mock.mjs       демо-данные: подборки, цифры (выдуманные), расчёт цвета акцента — можно менять
  dev/index.html     песочница (+ playground.js, playground.css)
  dev/seo.html       редактор SEO-страниц и своих анкет (+ seo-editor.js, seo-editor.css)
Анкеты для песочницы берутся из seo/creators.json (свои анкеты; изначально — имена, ссылки OnlyFans и фото
со StaySlutty). Цифры у них в песочнице выдуманные.
В dev-режиме подпись ссылки не проверяется (sig=dev), config.js подменяется локальным —
ваш рабочий config.js не трогается. Папка dev/ и package.json на Vercel не выкладываются (.vercelignore).

Превью в админке сайта тоже работает: сайт (папка OnlyCreateors) читает файлы прямо отсюда
(путь в .env сайта: WIDGET_DIR, по умолчанию ../faveradar-widget).

Выкладка на Vercel
------------------
1. Vercel → Add New → Project → импорт этой папки (или `npx vercel` в этой папке).
   Framework Preset: Other, Build Command: пусто, Output Directory: . (корень).
2. Settings → Domains → faveradar.xyz.
3. На сервере сайта в .env:
     WIDGET_URL=https://faveradar.xyz
     WIDGET_ORIGINS=https://faveradar.xyz
   (CORS: данные отдаются только блоку с этого домена).

Ссылки выглядят так: https://faveradar.xyz/?view=top&count=6&layout=photos&sig=...
Параметры подписаны: изменение любого из них или открытие без sig → «ссылка недействительна».
Отозвать все выданные ссылки: сменить EMBED_SECRET на сервере сайта.

Что можно менять свободно
-------------------------
Тексты (объект T в widget.js), оформление (widget.css), разметку карточек (photoCard / bigCard /
rowCard в widget.js). Не меняйте: имена параметров ссылки и формат ответа /widget-api/data —
их задаёт сервер сайта. Данные вставляются только через textContent (не innerHTML) — так и оставьте.

SEO-страницы
------------
Обычные HTML-страницы для Google прямо на домене виджета. Сайт и сервер данных в этом не участвуют:
всё хранится в этой папке и выкладывается на Vercel вместе с виджетом.
  https://www.faveradar.xyz/<адрес>      страница топа, например https://www.faveradar.xyz/best-onlyfans-creators
  https://www.faveradar.xyz/tops         список всех опубликованных топов (создаётся сам)
  https://www.faveradar.xyz/home         все анкеты из seo/creators.json (создаётся сам); сюда ведёт
                                         www.faveradar.xyz/ без подписи виджета
  любой другой адрес                     показывает тот же каталог всех анкет (для Google это 404, не дубль)
  https://www.faveradar.xyz/sitemap.xml  карта сайта — добавьте её в Google Search Console
  https://www.faveradar.xyz/robots.txt   разрешает индексацию и указывает на sitemap

Как править:
  1. Дважды щёлкните seo-editor.cmd (или start-dev.cmd и затем http://localhost:5173/dev/seo.html;
     из песочницы — ссылка «SEO-страницы» вверху). Редактор работает только на этом компьютере.
  2. Вкладка «Анкеты» — свои анкеты: ссылка на OnlyFans (username берётся из неё, трекинг-ссылки
     вида /c123 можно), имя, фото (https), описание, город, галочка «верифицирована».
  3. Вкладка «Страницы» — заголовок H1, адрес (сам предлагается из заголовка), title, description,
     ключевые слова, текст над и под анкетами («## Заголовок» в начале абзаца — подзаголовок),
     анкеты по порядку, галочка «Опубликована». «Превью» показывает страницу ещё до сборки, черновики тоже.
  4. Нажмите «Собрать страницы» — появятся pages/*.html, sitemap.xml и robots.txt
     Заодно новые фото анкет скачиваются и сжимаются в img/c/ (нужен ffmpeg в PATH; без него
     страницы просто берут исходные фото). Старые копии удаляются сами. Первая сборка ~1-2 минуты.
     (то же самое из терминала: node seo/build.mjs).
  5. Выложите папку на Vercel как обычно. Страницы откроются на faveradar.xyz/<адрес>.

Данные: seo/pages.json и seo/creators.json (их пишет редактор; можно править и руками, потом собрать).
Кнопка «View profile» и фото ведут прямо на ссылку анкеты (без счётчика кликов сайта).
Страницы на английском, оформление — из widget.css, окно 18+ — seo.js (текст страницы остаётся в HTML,
поэтому Google его видит). Другой домен: SITE_URL=https://другой.домен node seo/build.mjs.
Адреса — только строчные латинские буквы, цифры и дефисы; служебные (dev, pages, seo, tops, widget,
sitemap, robots, index) заняты. Файлы виджета не перекрываются: Vercel сначала отдаёт существующие файлы.

Уведомления в Telegram
----------------------
Заход на сайт (SEO-страницы и виджет, в том числе встроенный на чужой сайт) и переход по анкете
(«View profile», фото) присылают сообщение в Telegram: страница, источник, анкета и ссылка, страна, город,
устройство, браузер, IP. Заход — одно сообщение на страницу за сессию браузера, переход — на каждый клик.

Как это устроено: страница отправляет событие на /api/notify этого же домена (функция api/notify.mjs на Vercel),
а она уже пишет в Telegram. Токен бота в код не попадает — он хранится в настройках Vercel.

Настройка (один раз): Vercel → проект → Settings → Environment Variables:
  TG_TOKEN     токен бота от @BotFather (можно того же, что у StaySlutty)
  TG_CHAT_ID   id чата, куда писать
  TG_NOTIFY_VISITS=0 / TG_NOTIFY_CLICKS=0   — по желанию выключить один вид сообщений
После добавления переменных сделайте Redeploy. Без переменных функция молча ничего не шлёт.
Локально (npm run dev) сообщения не отправляются, а печатаются в окне сервера.

PDF-каталог анкет
-----------------
  node seo/pdf.mjs                       → dist/faveradar-creators.pdf — все анкеты из seo/creators.json
  node seo/pdf.mjs --page <адрес>        → dist/faveradar-<адрес>.pdf — анкеты одной SEO-страницы по порядку
Фото и кнопка «View profile» в PDF кликабельны и ведут на ссылку OnlyFans анкеты. Берёт сжатые фото из img/c
(сначала соберите страницы), печатает через Chrome или Edge. Папка dist/ не выкладывается и не попадает в git.

Куда ведут анкеты
-----------------
Фото и «View profile» на страницах faveradar.xyz ведут на страницу анкеты на faveradar.com
(https://www.faveradar.com/#/c/<ник>), а уже там — ссылка на OnlyFans. Анкеты должны быть на faveradar.com
с тем же ником (на сервере сайта: node scripts/import-stayslutty.mjs --keep-demo).
Вернуть прямые ссылки на OnlyFans: собрать страницы с пустым PROFILE_SITE —
  PowerShell:  $env:PROFILE_SITE=''; node seo/build.mjs
